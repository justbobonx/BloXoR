# BloXoR

HTML5 canvas port of the Android tilt-puzzle BloXoR.

Open `index.html` via a local server (GitHub Pages or any static host). File-open may fail puzzle fetches.

**Play:** arrows / WASD or drag on the board to tilt. Line up **O X O** in a straight adjacent row or column. Esc pauses. Tap a bomb to detonate.

```
assets/images/   art (whole_bg_ls, blx_*, effects)
assets/data/     PuzzleIndex.txt + level .txt files
assets/audio/    sfx_*.ogg
```
